# Nebula Knowledge Corpus

Purpose: durable, pragmatic implementation knowledge that should influence autoresearch ranking.

What to store here:
- Proven upgrade patterns that worked in Nebula.
- Rejected patterns and why they failed.
- Performance findings (before/after metrics).
- UX/readability heuristics for dense graph rendering.
- External reference distillations translated into local code constraints.

Autoresearch integration:
- `npm run nebula:autoresearch` scans this folder first.
- If empty, it falls back to `docs/examples` signals.
- Higher-quality notes here will produce more meaningful hypotheses.
